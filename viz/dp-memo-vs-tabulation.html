2 · Tabulation (bottom-up: just a loop)

    
No recursion, no call stack, no call log — because nothing is ever called. It starts at the base cases and walks up.

    The one difference that matters. Memoization asks “what do I need?” and dives down to find out — building a call
    stack n deep whether you wanted one or not. Tabulation says “I'll build up from the bottom”,
    so every value it needs is already behind it and there is nothing to call.

Both beat O(2ⁿ) the same way — each value is produced exactly once.
    Memoization enforces that with a lookup (the ⚡ step). Tabulation enforces it by never asking twice in the first place.
